# QUANTARA Services website

Static website for quantaraservices.in. Plain HTML, CSS and JavaScript, no build step.

- Pages: `index.html`, `services.html`, `about.html`, `industries.html`, `careers.html`, `contact.html`, `404.html`
- Styles and scripts: `assets/`
- Hosting: Cloudflare Pages (build command: none, output directory: `/`)
- Contact form: sends enquiries by email to contact@quantaraservices.in via FormSubmit
